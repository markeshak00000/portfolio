INFINITY MEN2 — IMAGE-FIXED PORTFOLIO

This is a SINGLE-FILE website. All 8 images (developer portrait, Infinity MEN2 logo,
and six technology visuals) are embedded directly inside index.html.

DEPLOY TO GITHUB PAGES:
1. Open your portfolio repository.
2. Replace the old index.html in the repository root with this index.html.
3. You do NOT need an assets folder or separate image uploads.
4. Commit the change to the branch/folder configured for GitHub Pages.
5. After deployment, refresh the site with Ctrl+F5 (or open it in a private window).

If GitHub Pages uses a /docs folder, place index.html in /docs instead of the repository root.
